# React Login Component

## Project Description

React Login Component is a login and register responsive form creating with HTML5, CSS3, JS, React.js.

## Features

- Walidation data
- Responsiv Web Design
- Univeral Design

## Technologies

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3

## Installation

To run the project locally, follow these steps:

1. Clone the repository:

`git clone https://github.com/SebastianK2000/React_component.git`

2. Navigate to the project directory:

`cd reactComponent`

3. Install dependencies:

`npm install`

4. Run the application in development mode:

`npm start`

The application should be accessible at `http://localhost:3000`.

## Usage

After launching the application:

1. Enter a city name in the search field.
2. Click the "Search" button or press Enter.
3. Browse the displayed weather information.
